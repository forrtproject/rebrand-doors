# Doors preview

The preview of the Doors redesign of forrt.org, served at <https://forrt.org/rebrand-doors/>. It carries noindex and is not the live site.

- `gh-pages` is the built site. `rebrand-preview.yaml` in [forrtproject.github.io](https://github.com/forrtproject/forrtproject.github.io) overwrites it on every push to the `rebrand-doors` branch, so do not edit it here.
- `baseline` holds screenshots and page weights of the site before the redesign, for comparison.

Delete this repository after the redesign launches.
